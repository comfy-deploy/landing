Qwen-Image 2.1 is the latest image model from Alibaba's Qwen team, and it runs natively in ComfyUI. It has 7 billion parameters, open weights, native 2K output, and one feature most open models lack: it generates a real alpha channel, so cutouts come out with transparent backgrounds.

## What is Qwen-Image 2.1?

According to the ComfyUI team, Qwen-Image 2.1 uses an optimized MMDiT architecture, the same class as Qwen-Image 2.0, which shipped in February 2026. One checkpoint handles both generation and editing, which keeps your model folder simple compared with setups that need a separate editing model.

The announcement is on the [ComfyUI blog](https://blog.comfy.org/p/qwen-image-21-in-comfyui-open-weight). Check the model card on Hugging Face for the license before commercial use, since this post does not state it.

## Key features

These are the highlights as ComfyUI describes them:

- **RGBA output.** The model produces four channels, alpha included. Sprites, logos, icons, and product cutouts can go straight into a composite without a background-removal or matting step. ComfyUI says no other major open model does this.
- **Native 2K generation.** Output is 2048x2048 directly, not upscaled.
- **Up to 10 reference images.** The Text Encode Qwen Image 2.1 node opens image inputs as you fill them, up to 10. Characters, products, background plates, and style references are all read by the text encoder.
- **One checkpoint.** Generation and editing use the same weights.
- **7B parameters.** ComfyUI describes inference as fast and the weights as a good fit for consumer cards.

## Qwen-Image 2.1 ComfyUI workflow

To get started:

1. Update ComfyUI to the latest version.
2. Download the Qwen-Image 2.1 weights from Hugging Face and place them in your models folder.
3. Load the Qwen-Image 2.1 template from the Templates panel.
4. Write a prompt, attach references starting at `image_1`, and run.

If you have used the first-generation Qwen-Image graphs, the structure will look familiar. Our [Qwen-Image edit workflow](/workflows/qwen-image-edit-native) shows a native graph with the same prompt-plus-image pattern, and our earlier [Qwen Image Edit guide](/blog/qwen-image-edit) covers the editing side of the family. More graphs are collected under [Qwen-Image workflows](/workflows/model/qwen-image). Those pages target the earlier model, so use the 2.1 template for the new loaders and encode node.

## Where transparency helps

Transparent output changes a few common jobs:

- **Game and app assets.** Generate a sprite or icon and drop it onto a scene without edge cleanup.
- **Product cutouts.** Produce an item on a clear background for catalogs or ad layouts.
- **Logos and stickers.** Keep soft edges and partial transparency that a hard mask would lose.
- **Compositing pipelines.** Generate foreground elements separately from the background plate, then combine them in code or in another workflow.

We have not tested edge quality on hair, glass, or smoke, so check those cases against your own requirements.

## Qwen-Image 2.1 vs FLUX 3 Image Klein

Both are recent open-weight image models with multi-reference editing. Black Forest Labs reports, in internal evaluations relayed by ComfyUI, that its FLUX 3 Image Klein scores above Qwen-Image 2.1 on text-to-image and multi-reference generation. Those evaluations are not independent, so compare both on your own prompts.

From the published specs, Qwen-Image 2.1 offers native alpha output, a 7B size, and up to 10 references. Klein is 5.6B, adds bounding boxes for layout, and ships a base checkpoint for fine-tuning. If transparency is a hard requirement, the first one is the stronger candidate. If you need to pin elements to regions of the canvas, look at Klein.

## How to run Qwen-Image 2.1 in the cloud

A 7B model fits on mid-range cloud GPUs, which makes it cheap to try. Our earlier Qwen-Image workflow pages recommend an L40S class GPU for the first-generation model, and that is a sensible starting point here too. Many reference images and 2K output raise memory use, so size up if you hit limits. We have not benchmarked Qwen-Image 2.1 ourselves, and requirements depend on precision and resolution.
