Google Nano Banana is the nickname for the image editing capabilities of Gemini 2.5 Flash Image, which Google released on August 26, 2025. It edits an image from a plain-language prompt, keeps a character recognizable across edits, and can combine elements from several images into one scene.

![Google Nano Banana AI image editing](./nano-banana/cover.jpg)

Credit: [@minux302](https://x.com/minux302/status/1960358882100039859)

## What is Google Nano Banana?

Google describes Nano Banana as a major upgrade to image editing in Gemini. You describe the change you want, such as a new background or a different expression, and the model applies it to your image without manual masking or layer work.

According to Google, the model keeps character identity and scene coherence across multiple editing rounds, and it can blend elements from different images. This puts it in direct competition with open editing models such as Qwen Image Edit and FLUX.1 Kontext. You can read Google's description in the [official blog post](https://blog.google/intl/en-mena/product-updates/explore-get-answers/nano-banana-image-editing-in-gemini-just-got-a-major-upgrade/).

## Key features of Nano Banana

- **Natural language editing.** Change an image with a short description, for example "change the background to a forest" or "make the subject smile and adjust the lighting".
- **Character consistency.** The subject keeps recognizable features across edits, even when the angle, lighting, or background changes.
- **Multi-image fusion.** You can blend several images into one scene, which is useful for composites or for adding an element from another photo.
- **Multi-turn editing.** You can refine an image with successive prompts and build up detailed edits in layers.
- **ComfyUI integration.** ComfyUI supports the model through its API nodes, for both text-to-image and image-to-image workflows.

## Nano Banana pricing and availability

Developers and enterprises can use Nano Banana through three Google platforms:

- **Gemini API.** Direct API access for developers.
- **Google AI Studio.** An interactive development environment.
- **Vertex AI.** Google Cloud's enterprise platform.

Google lists developer pricing at $30 per million output tokens, which comes to about $0.039 per image.

ComfyUI supports Nano Banana (Gemini 2.5 Flash Image) through native API nodes, so you can run Google's editing model on the ComfyUI canvas next to your other nodes. Both text-to-image and image-to-image workflows are supported.

## Which image editing model should you choose?

**Choose Nano Banana for natural language workflows.** It suits intuitive editing commands, multi-image fusion, and teams that already use Google tools, such as content creators and businesses.

**Choose Qwen Image Edit for precise control.** It fits professional workflows that need exact element changes and bilingual text editing, such as graphic design. Read our [Qwen Image Edit guide](/blog/qwen-image-edit) for details.

**Choose FLUX.1 Kontext for rapid iteration.** It suits creative experimentation with fast processing and multi-turn editing, which helps artists and developers who need quick results. Read our [FLUX.1 Kontext Dev guide](/blog/flux-kontext-dev) and browse the [Flux Kontext workflows](/workflows/model/flux-kontext).

Each model has different strengths, so run the same prompt through each one to see which fits your workflow.
