## How it works

This is a Nano Banana workflow built for restoration. It does not run a local upscaler or face restorer. Instead, Google's Gemini 2.5 Flash Image model (google/gemini-2.5-flash-image-preview) is called through OpenRouter, and the model redraws the photo as a restored, colorized version.

The scan you upload is loaded with LoadImage and fitted to the selected aspect ratio by a ResizeAndPad node. The BananaTaskGenerator and LLMPromptManager nodes from llm-toolkit build the instructions, and anything you type in the extra prompt field is added to them. A PreviewAny node shows the final prompt. GenerateImage sends the image and prompt to the model with your OpenRouter key and SaveImage stores the output.

Because the heavy work happens in the external model, the recommended GPU is a small T4.

## Tips

- Scan at a reasonable resolution and crop out the scanner bed before uploading.
- Use the extra prompt to guide the result, for example the decade of the photo or the clothing colors you know are correct.
- Compare faces with the original. Generative restoration can alter small details, so run a few seeds and keep the closest one.
- Choose the aspect ratio closest to the original so less padding is added.

## Run it as an API

Deploy the workflow on ComfyDeploy to restore photos from a web form or batch script.
