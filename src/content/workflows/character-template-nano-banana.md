## How it works

This is a Nano Banana workflow, meaning the image generation is done by Google's Gemini 2.5 Flash Image model (google/gemini-2.5-flash-image-preview) through OpenRouter. There are no local checkpoints to load, which is why it fits on a small GPU.

Your subject image goes through a ResizeAndPad node that fits it to the aspect ratio you pick (square, 3:4, 4:3, 9:16 or 16:9). A BananaTaskGenerator node and the LLMPromptManager from the llm-toolkit package combine your style prompt with the task instructions. Then the GenerateImage node sends the padded image and the prompt to the model, using the provider selector and the OpenRouter config node, and the result is saved with SaveImage.

The playground inputs are the subject image, the style prompt, an extra prompt, the aspect ratio, a seed, the model choice and your API key.

## Tips

- The image is padded to the chosen ratio, not cropped. Crop your reference first so the character sits well in the frame.
- Keep the style prompt short and concrete, such as an era, medium or game genre.
- Use the extra prompt field when you want a specific edit. It accepts a full instruction if no OpenAI key is set in machine secrets.
- Change the seed to get a different variation of the same prompt.

## Run it as an API

Once deployed on ComfyDeploy, the workflow becomes an endpoint you can call from your own app or pipeline.
