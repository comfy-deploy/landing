## How it works

The subject and garment images each pass through a ResizeAndPadImage node, which pads them to the aspect ratio you pick. A ResolutionSelector sets the size, and ImageBatch combines the two pictures into one input for the model.

A prompt chain from the `llm-toolkit` package, using PrimitiveStringMultiline and LLMPromptManager, wraps your text. The ConfigGenerateImageOpenRouter and APIProviderSelectorNode nodes point the GenerateImage node at OpenRouter with your key and the Gemini image model. It returns the finished picture, and SaveImage stores it.

Because the model runs through an API, the workflow does not load any local weights.

## Tips

- Crop and format your subject image to the aspect ratio you choose, since the image is padded rather than stretched.
- Use a clear garment photo on a plain background.
- The prompt can also set the scene, for example placing the person in a rustic cafe with warm light.
- Use the n input to request more than one image per run and pick the best.

## Run it as an API

You can deploy this workflow on ComfyDeploy as a hosted API endpoint. The inputs listed above become the request fields, so your own app can submit them and receive the finished result without running ComfyUI yourself. The same workflow can also be run and shared from the ComfyDeploy playground in your browser.
