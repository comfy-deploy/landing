## How it works

This Nano Banana workflow uses Google's Gemini 2.5 Flash Image model (google/gemini-2.5-flash-image-preview) through OpenRouter. The description asks you to bring your own OpenRouter key, which you paste into the external_api_key input.

The character or prop image is loaded and resized with ImageResizeKJv2 from comfyui-kjnodes, then a ResolutionSelector picks the output size from the aspect ratio you choose. The LLMPromptManager and BananaTaskGenerator nodes from llm-toolkit assemble the task text from your style prompt. GenerateImage then calls the model with the image and prompt, and SaveImage writes the result.

Compared with the other Nano Banana templates, this one resizes with the KJ node instead of padding, and it defaults to a portrait 9:16 layout, which suits a guide page.

## Tips

- Upload a subject on a clean background so the layout stays readable.
- Describe the era and genre in the style prompt, such as the Sega Saturn RPG look in the example.
- Portrait 9:16 is the default. Try 3:4 if you plan to print the page.
- Change the seed to explore different layouts without rewriting the prompt.

## Run it as an API

On ComfyDeploy you can expose this workflow as an endpoint and pass the image, style and key from your own tool.
