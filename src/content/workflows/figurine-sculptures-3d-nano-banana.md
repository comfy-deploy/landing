## How it works

This workflow has no local diffusion model. The model list is empty, and the image is generated by Gemini 2.5 Flash Image (nicknamed Nano Banana) through OpenRouter, using the llm-toolkit custom nodes.

Your subject photo is loaded and passed through ResizeAndPadImage, which pads it to the size chosen by ResolutionSelector (square, 3:4, 4:3, 9:16 or 16:9). A BananaTaskGenerator and LLMPromptManager combine your short prompt with a built-in task description for figurine sculptures. APIProviderSelectorNode and ConfigGenerateImageOpenRouter point the GenerateImage node at the OpenRouter model, using your key, and SaveImage stores the result.

The default prompt is short and descriptive, for example wireframe and a high-end streamer setup, which the model turns into a figurine with that theme.

## Tips

- Crop the source image to the aspect ratio you pick. The notes warn that the image is padded to size, so a mismatch leaves visible borders.
- Use the extra prompt field for specific changes, such as swapping an object or keeping the same clothing with a logo that wraps the fabric.
- If you run without an OpenAI key on the machine, write your full prompt by hand and remove the system prompt step.
- Try the free model variant for tests and the standard one for final output.
