## How it works

Insta Pic is a Nano Banana workflow. The generation is handled by Google's Gemini 2.5 Flash Image model (google/gemini-2.5-flash-image-preview, with a free variant listed) via OpenRouter, so no model files are loaded on the GPU.

Your subject photo is loaded and passed through a ResizeAndPad node so it matches the aspect ratio you choose. The text you type, such as a city name and camera angle, goes into the LLMPromptManager together with a BananaTaskGenerator node that supplies the task instructions. A PreviewAny node shows the final prompt text. The GenerateImage node then sends image and prompt to the model with the OpenRouter configuration and saves the result with SaveImage.

The inputs you see in the playground are the subject image, location prompt, extra prompt, aspect ratio, seed, model choice and your API key.

## Tips

- Use a clear photo where your face and body are visible and not cut off, since the image is padded rather than cropped.
- Add camera language to the location, for example a low angle or close-up, as in the default Hong Kong prompt.
- Pick the aspect ratio for the destination: 9:16 for stories, 3:4 or 1:1 for feed posts.
- Re-run with a new seed if the first result changes your face too much.

## Run it as an API

Deploy it on ComfyDeploy to call it from a script or app that sends a photo and a location.
