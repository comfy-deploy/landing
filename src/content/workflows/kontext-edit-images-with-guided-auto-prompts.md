## How it works

This workflow edits with `flux1-kontext-dev.safetensors`, `clip_l`, `t5xxl_fp8_e4m3fn_scaled` and `ae.sft`. Two input images are resized with `ImageResizeKJv2` and `FluxKontextImageScale`, optionally have backgrounds removed with `BiRefNetRMBG`, and are stitched together with `ImageStitch`. They are encoded and passed to `ReferenceLatent` so Kontext can use both.

The prompt is generated by an LLM. The `llm-toolkit` nodes send your action prompt and an AI_SYSTEM_PROMPT, which tells the model to act as Kontext and write a single flowing paragraph, to an OpenAI model (default `gpt-4.1-mini`). The generated text is shown and fed to `CLIPTextEncode`.

Sampling uses `KSamplerWithNAG`, so a negative prompt has an effect. `FluxGuidance` and `FluxDisableGuidance` handle guidance, and `ModelSamplingFlux` sets the schedule. A `VideoResolutionSelector` sets size from the aspect ratio. The workflow also includes Kontext prompting notes and an image comparer.

## Tips

- Keep the action prompt short, such as converting a character to realistic style, and let the LLM expand it.
- Steps default to 20. Lower it for quick drafts.
- Edit the negative prompt to block problems like short legs or a big head.
- Without an OpenAI key, write the full Kontext prompt manually.
